Follow the installation instructions in the [plugin README](../../README.md). Have the user download and verify the bridge and run `xematik-channel login`. Restart Codex and complete Xematik sign-in when prompted. Explain that an independent supervisor is needed for the watcher to outlive a turn; otherwise use `await_feedback` polling. For custom servers, follow the [README's local marketplace instructions](../../README.md). Never expose tokens.
